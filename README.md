# 💬 Closeby — Local Proximity & Multi-Hop Texting

A clean, daylight-themed **Proximity & Multi-Hop Chat** web app that lets people text within close physical distances (`50 yd`, `250 yd`, `1 mi`, or `Global`).

## ✨ Features
- **Real Names & Initials:** Uses your PIN-locked real name and initials with custom badge colors instead of random nicknames.
- **Focused Texting Layout:** Main **Messages** view for broadcasting to everyone nearby or chatting 1-on-1 with people around you.
- **Dedicated Radar & Range Tab:** Separate tab with a live proximity map, range controls (`50 yd`, `250 yd`, `1 mi`, `Global`), GPS toggle, and 15-yard walk simulator.
- **Multi-Hop Relay:** Messages can hop across nearby devices to extend range.
- **Works Everywhere:** Connects across browser tabs, local Wi-Fi (`server.js`), and globally on **GitHub Pages** (`MQTT over WSS`).

## 🚀 Run Locally
```bash
node server.js
```
Open `http://localhost:3000` in your browser.
